# Contributing

Thanks for your interest in Ray. **This project is not accepting outside contributions at this time.**

- Pull requests from people outside the project will be closed without review.
- Issues, discussions, and comments are limited to existing collaborators.

You're welcome to fork the repository and use the code under the terms of the
[Apache License 2.0](LICENSE).

This policy may change in the future. If it does, this file will be updated.
