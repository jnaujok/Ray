# Fonts

Fonts the sample scenes set `text` objects in (see the `text` object in
[`../README.md`](../README.md)).

| File | What it is |
|------|------------|
| `Lato-Bold.ttf` | [Lato](https://www.latofonts.com) Bold by Łukasz Dziedzic (tyPoland), from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/lato): TrueType outlines, 2,000 units to the em, with GPOS pair kerning. Included unmodified. It is licensed under the [SIL Open Font License 1.1](OFL.txt), not under this project's Apache License; see [`../../NOTICE`](../../NOTICE). |
| `OFL.txt` | The font's license, as it comes with it. |
